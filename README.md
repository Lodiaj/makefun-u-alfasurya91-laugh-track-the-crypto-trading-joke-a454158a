One line about crypto trading life, under 200 characters, written by a small
program. `main.ts` writes a single joke to `/output/entry.txt`.

The joke:

> The group chat called it a generational entry, so I bought the top. Now my bags are generational too.

## Run

```sh
node main.ts
```

It writes the joke to `/output/entry.txt` (1–200 characters, a single line).
